# Endpoints

- **[Repos and records](records.md)**: The `at://` URL structure, the resolution chain, repos, collections, single records, blobs and CAR exports.
- **[Identity](identity.md)**: Resolving a handle or DID, the DID document, a trace of every resolution step, and a `did:plc` identity's PLC history.
- **[Network](network.md)**: Discovering repos by collection, backlinks through Constellation, and lexicon resolution through DNS.
- **[Labels](labels.md)**: Labels on records and accounts, from Bluesky's moderation labeler, every known labeler, or any you name.
- **[XRPC](xrpc.md)**: One service URL for the whole network, with each XRPC call routed to the server that answers it, for Bluesky and other apps.
- **[Stats](stats.md)**: The anonymous usage dashboard and how to reset it.
